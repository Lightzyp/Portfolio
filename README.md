# Daniel Macharia — Project Guide

Software, database and security coursework from East Tennessee State University, plus a documented Ubuntu security lab. Choose an area below to go straight to the code.

## Software

- **Library Management System**: manages books, users, loans and returns in a browser, with book and user records saved to CSV.  
  C#, ASP.NET Core Blazor, MSTest · [Library code](https://github.com/Lightzyp/Lab-6)
- **Modular Course Catalog**: validates course data and models enrollment, open seats and waitlists, with results shown in the browser console.  
  JavaScript modules, classes, closures · [Catalog code](https://github.com/Lightzyp/coursework/tree/main/csci-3110/lab-04-course-catalog)

## Databases

- **Doctor and Patient Appointments**: creates, edits and deletes appointments through an explicit many-to-many join entity.  
  ASP.NET Core MVC, Entity Framework Core, SQLite · [Appointments code](https://github.com/Lightzyp/coursework/tree/main/csci-3110/lab-03-many-to-many-crud)
- **ShinraNet API**: backend for a social media project, with REST endpoints for users, posts and likes.  
  Python, FastAPI, SQLite, SQL · [ShinraNet code](https://github.com/Lightzyp/coursework/tree/main/csci-2910/project-01-shinranet)

## Security

- **Ubuntu Server Hardening Lab**: documents securing a lab virtual machine with SSH keys, a firewall, Fail2Ban and automatic updates.  
  Linux, SSH, UFW, Fail2Ban · [Hardening lab](https://github.com/Lightzyp/ubuntu-server-hardening)
- **Security Lab Reports**: covers vulnerability scanning and firewall rules on classroom virtual machines, plus policy analysis.  
  Kali Linux, Nessus, Nmap, iptables · [Security reports](https://github.com/Lightzyp/coursework/tree/main/csci-3500)
